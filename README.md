# 小米平板 DP-in 输入增强

把小米平板用 USB-C 接到 Windows 电脑，可以用 DP-in 功能让它充当一块外接数位屏，支持触摸和手写笔，如果买了配套的键盘盖，还能用键盘和触控板。但是原厂对这些外设支持得并不好（有可能是为了兼容性）：
1. 触控板被映射为鼠标，触控板手势翻译成快捷键，
2. 写字时可能遇到掌侧碰屏误触。
3. 小米焦点触控笔 Pro 的很多高级功能，例如旋转、触控键滑动，无法使用

这个 KernelSU 模块让 Windows 直接收到触控板的多指数据、触屏接触数据和更完整的笔数据。平时在平板上继续使用 Android。接线进入 DP-in 后自动启用，退出或断开后恢复平板本地输入。

## 装好以后能做什么

| 你怎么用 | Windows 收到什么 |
| --- | --- |
| 在键盘盖触控板上移动、滚动、点击或拖动 | Windows 将它识别为「精确式触摸板」。可在 Windows 设置里调整多指手势 |
| 用手指点触屏 | 保留多点触控，并给 Windows 提供**触点可信度**，帮助过滤掌侧误触 |
| 用小米焦点触控笔 Pro 写字和画画 | 笔尖位置、悬停、压感、倾斜和**绕笔杆旋转**。笔触效果取决于绘画软件 |
| 轻捏或双击笔身 | 轻捏按住发送笔侧键 1，松开发送释放。双击发送一次笔侧键 2 |
| **沿笔身滑动** | 朝笔尖发送 `F15`，反向发送 `F16`。在支持这些键的应用里可以绑定调笔刷大小等动作 |

在已测的键盘盖上，触控板实际报告过最多三个有效手指。触屏的防误触有可调门限，力度较重的手指也可能被过滤。绘画软件能否使用侧键 2 和笔杆旋转，要看它支持的笔输入功能。

## 开始使用

1. **看型号和连接。** 已验证的是小米平板 9 Pro Max（M367FC／`yingtian`）、HyperOS `OS4.0.16.0.XBMCNXM` 上的指定原厂 USB 服务，以及 Windows 11。USB-C 连接需要同时提供 DP 视频和 USB 数据。
2. **下载模块 ZIP。** 平板需已具备可用的 KernelSU root 和系统挂载支持。在 [GitHub Release](https://github.com/neoncloud/xiaomi-pad-dpin-hid/releases/latest) 下载模块的 \`codex_usb_ptp_touchpad_native-*.zip\`。也可以使用自己平板上的原厂文件，[从源码构建](docs/BUILD.md)。
3. **安装并试用。** 在 KernelSU 里安装生成的 ZIP，按 [安装和恢复说明](docs/INSTALL.md) 让模块生效，再走平板原有的 DP-in 入口。Windows 识别设备后即可使用。

安装和构建时会用到电脑。日常使用由平板本地自动处理。使用临时 root 时，整机重启后先恢复 root 并确认模块启用。

当前模块版本是 **3.1.6**。有兴趣了解它怎样接收和转发输入，可以读 [实现原理](docs/ARCHITECTURE.md)。
